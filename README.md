# goit-rdb-hw-03

Домашня робота №2 з теми **«Завантаження даних та основи SQL. DQL-команди»**.

## Датасет

Для виконання роботи використано датасет **UCI Adult/Census Income**.

Офіційне джерело:  
https://archive.ics.uci.edu/dataset/2/adult

Датасет містить **48 842 записи**. Дані включають демографічні та соціально-економічні характеристики людей, а цільова ознака `income` показує, чи перевищує річний дохід 50 000 доларів.

Для роботи використовується весь доступний набір даних без додаткової вибірки.

## Отримання даних

Дані завантажуються безпосередньо з UCI Machine Learning Repository за допомогою пакета `ucimlrepo`:

```python
from ucimlrepo import fetch_ucirepo

adult = fetch_ucirepo(id=2)
```

Після завантаження ознаки та цільова колонка об'єднуються в один DataFrame. Отримані дані зберігаються у CSV-файл, який використовується для подальшого імпорту в PostgreSQL.

## PostgreSQL та завантаження даних

PostgreSQL запускається безпосередньо у Google Colab за допомогою пакета `pgserver`.

Спочатку створюється staging-таблиця `hw3_adult_staging`, у якій сирі дані зберігаються як `TEXT`.

CSV-файл завантажується у staging-таблицю за допомогою `COPY FROM STDIN`.

Після цього створюється типізована таблиця `hw3_adult_clean`. Під час перенесення даних виконуються очищення, приведення типів та нормалізація пропущених значень.

Спеціальний маркер `?` у категоріальних колонках перетворюється на SQL `NULL`.

## Запуск у Google Colab

Notebook розрахований на запуск у **Google Colab з Python 3.12**.

Під час виконання роботи було виявлено, що в середовищі Colab з Python 3.13 пакет `pgserver` не встановлювався. Для коректної роботи було використано доступну версію runtime **2026.07**, яка працює з Python 3.12.

### Налаштування середовища

Перед запуском notebook:

1. Відкрити notebook у Google Colab.
2. У верхньому меню вибрати **Runtime → Change runtime type**.
3. Вибрати версію runtime **2026.07 (Python 3.12)**.
4. Зберегти налаштування.
5. Виконати **Runtime → Restart session and run all**.
6. Дочекатися виконання всіх клітинок notebook.

На початку notebook автоматично встановлюються необхідні бібліотеки:

```python
%pip install -q pgserver psycopg2-binary sqlalchemy pandas pyarrow ucimlrepo
```

PostgreSQL запускається безпосередньо в середовищі Colab, тому окремо встановлювати або налаштовувати PostgreSQL не потрібно.

Для запуску сервера та створення підключення використовується:

```python
import pandas as pd
import pgserver
from sqlalchemy import create_engine, text

pg = pgserver.get_server('/tmp/hw3_pg', cleanup_mode='stop')
engine = create_engine(pg.get_uri(), future=True)
```

Після цього notebook автоматично:

1. завантажує датасет UCI Adult;
2. створює CSV-файл;
3. створює staging-таблицю;
4. імпортує дані через `COPY FROM STDIN`;
5. створює та заповнює clean-таблицю;
6. виконує перевірки якості даних;
7. виконує EDA та DQL-запити.

> **Примітка:** якщо під час встановлення `pgserver` з'являється помилка `No matching distribution found`, потрібно перевірити версію Python у Google Colab. Для цього notebook використовувався Python 3.12.

## Основні результати

Після завантаження отримано **48 842 записи**.

Під час аналізу було виявлено пропущені значення у категоріальних колонках `workclass`, `occupation` та `native_country`. Значення `?` були нормалізовані до SQL `NULL`.

Перевірка також показала **52 потенційні повні дублікати**. Вони не видалялися автоматично, оскільки датасет не містить гарантованого природного ідентифікатора людини.

Для числових ознак було розраховано базову статистику та стандартне відхилення. Окремо перевірено великі значення `hours_per_week`, які були залишені в датасеті як можливі рідкісні, але допустимі спостереження.
